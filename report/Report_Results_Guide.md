# Report workflow

1. Run `python src/train.py` to download the UCI dataset and generate actual metrics, charts and model files.
2. Run `python src/build_report.py` to create `report/Project_Report_Completed.docx`, which includes the measured scores and generated visualizations.
3. Fill in student details, GitHub URL and hosted Streamlit URL (if deployed).
4. Read the results and discussion and ensure it accurately describes your run. Do not fabricate results.
