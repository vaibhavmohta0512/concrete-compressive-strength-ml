# Dataset

Download the dataset from the official UCI page:
https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength

The project code fetches it using `ucimlrepo` (dataset ID 165) and saves a local CSV in this folder when run. The dataset has 1,030 rows, eight numerical input features, and one numerical target. Attribute units and licensing are documented by UCI. Please cite Yeh (1998) and the UCI repository in submitted work.
